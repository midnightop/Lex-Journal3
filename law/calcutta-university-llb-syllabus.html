CU Scale Definition

Evaluation Architecture

1. Percentages to Letter Grade Boundaries

• 90 to 100 : O (Outstanding) [GP: 10]

• 80 to below 90 : A+ (Excellent) [GP: 9]

• 70 to below 80 : A (Very Good) [GP: 8]

• 60 to below 70 : B (Good) [GP: 7]

• 50 to below 60 : B+ (Above Good) [GP: 6]

• 40 to below 50 : C (Average) [GP: 5]

• 30 to below 40 : P (Pass) [GP: 4]

• Below 30 / Absent : F / AB (Fail) [GP: 0]

2. Computational Index Formulas

Credit Points : Achieved by multiplying credits in a course with grade point scored (4 credits assigned per 100 marks module).

SGPA Formulation : Expressed up to 2 decimal places using the mathematical expression value: SGPA (Si) = Σ(Ci x Gi) / ΣCi.

CGPA Architecture : Measures aggregate tracking over continuous evaluation tiers: CGPA = Σ(Ci x Si) / ΣCi.

3. Operational Passing Clauses

  • Candidates must secure a clean minimum metric of 30% marks across each paper to satisfy pass standards.
  • Promotion occurs if a candidate fails to clear up to two subjects, provided class metrics remain valid.
  • A single grace mark parameter may clear failures inside thin operational boundaries.
